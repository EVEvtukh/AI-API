# AI Assistant CLI

Меню-интерфейс для генерации ответов через **GenAPI** (https://gen-api.ru/).

Поддерживает выбор готовых сценариев, свободный ввод запроса и добавление собственных задач.

---

## Быстрый старт

```powershell
# 1. Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\Activate.ps1

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Скопировать шаблон ключей и подставить реальные значения
Copy-Item .env.example .env
# Откройте .env и замените значения-заполнители на свои ключи

# 4. Запустить интерфейс
python cli.py
```

## Интерфейс cli.py

При запуске `python cli.py` появляется меню:

```
============================================================
  AI ASSISTANT CLI — меню
============================================================
  Загружено сценариев из prompts.json: 10

   1. Показать список задач
   2. Запустить задачу из prompts.json
   3. Свободный запрос (свой текст)
   4. Добавить свою задачу
   5. Удалить задачу
   0. Выйти

  Выберите действие:
```

### Описание пунктов

| № | Действие | Описание |
|---|---|---|
| 1 | Показать список задач | Выводит подробную информацию о каждом сценарии (роль, контекст, формат ответа) |
| 2 | Запустить задачу | Выбирает сценарий из `prompts.json`, предлагает тестовый ввод, отправляет в API |
| 3 | Свободный запрос | Вводите роль и текст вручную — без привязки к сценариям |
| 4 | Добавить свою задачу | Пошаговый ввод: название, роль, контекст, вопрос, формат, тестовый ввод. Сохраняет в `prompts.json` |
| 5 | Удалить задачу | Выбирает номер задачи для удаления из `prompts.json` |
| 0 | Выйти | Завершает работу |

### Как запустить задачу

```
  Выберите действие: 2

  Доступные задачи:
    1. Анализ текста
    2. Генерация кода
    ...

  Номер задачи: 1

  Сценарий: Анализ текста
  Роль:     Ты - эксперт по анализу текста и лингвистике
  Формат:   Ответ должен содержать: 1) Общую оценку текста...
  Тестовый ввод: Искусственный интеллект революционизирует мир...

  Ввод (Enter = использовать тестовый):
  Temperature (Enter = 0.7):
  Max tokens (Enter = 2048):

  Отправка запроса...

  --- Ответ модели ---
  ## 1. Общая оценка текста
  ...
```

### Как добавить свою задачу

```
  Выберите действие: 4

  --- Добавление новой задачи ---
  Название: Моя задача
  Роль (например: Ты — дизайнер): Ты — UX-исследователь
  Контекст (когда применять): При анализе интерфейсов и пользовательского опыта
  Вопрос / задание: Оцени usability интерфейса
  Формат ответа: 1) Сильные стороны, 2) Проблемы, 3) Рекомендации
  Тестовый ввод: Интерфейс интернет-магазина с корзиной и чекаутом
```

Задача сохраняется в `prompts.json` и появляется в меню сразу.

## prompts.json

Файл хранит список сценариев. Каждый объект содержит:

| Поле | Описание |
|---|---|
| `id` | Уникальный номер задачи (авто-инкремент) |
| `name` | Название (показывается в меню) |
| `role` | Системная роль для модели |
| `context` | Контекст использования |
| `question` | Вопрос / задание |
| `format` | Формат ожидаемого ответа |
| `test_input` | Тестовый ввод по умолчанию |

### Пример структуры

```json
{
  "prompts": [
    {
      "id": 1,
      "name": "Анализ текста",
      "role": "Ты - эксперт по анализу текста и лингвистике",
      "context": "Пользователь предоставляет текст для анализа",
      "question": "Проанализируй предоставленный текст...",
      "format": "Ответ должен содержать: 1) Общую оценку...",
      "test_input": "Искусственный интеллект революционизирует..."
    }
  ]
}
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните ключи:

| Переменная | Описание | Обязательна |
|---|---|---|
| `GENAPI_API_KEY` | Ключ API для GenAPI (https://gen-api.ru/) | Да |
| `OPENAI_API_KEY` | Ключ API для OpenAI (платформа.openai.com) | Нет |
| `PROXYAPI_API_KEY` | Ключ API для ProxyAPI (proxyapi.ru) | Нет |

> **Важно:** файл `.env` **не** попадает в git — он записан в `.gitignore`.

## Скрипты и их назначение

| Файл | Назначение |
|---|---|
| `cli.py` | **Интерфейс меню** — основной инструмент (рекомендуется) |
| `genapi_request.py` | Прямой вызов GenAPI (без меню, через `input()`) |
| `proxyapi_request.py` | Прямой вызов через ProxyAPI |
| `openai_direct.py` | Прямой вызов OpenAI (по умолчанию отключён) |

`cli.py` использует функции из `genapi_request.py` и добавляет меню, добавление/удаление задач.

## Безопасность

1. **Никогда** не коммитьте `.env` — ключи API попадут в публичный репозиторий
2. **Регулярно** отзывать скомпрометированные ключи на сайтах провайдеров
3. **Не присылайте** ключи в чат — их невозможно удалить из истории сообщений

## Решение проблем

### «Не-ASCII символы в ключе»

Если ключ содержит кириллицу, скрипт выводит понятное сообщение:

```
Ошибка: GENAPI_API_KEY содержит недопустимые (не-ASCII) символы: абв
Похоже, вместо реального ключа оставлен заполнитель из примера.
```

Откройте `.env`, замените заполнитель на реальный ключ (только латиница и цифры) и перезапустите.

### «Виртуальное окружение не найдено»

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### «Модуль не найден»

Убедитесь, что виртуальное окружение активно:

```powershell
# Проверка
$env:VIRTUAL_ENV

# Если пусто — активируйте
.venv\Scripts\Activate.ps1
```

### «CommandNotFoundException: genapi_request.py»

PowerShell не запускает `.py` файлы напрямую. Используйте:

```powershell
python genapi_request.py    # ✅ правильно
genapi_request.py           # ❌ ошибка
```
